# Vocal Expression and Realism (Text-Only)

For Azure Neural TTS, we must use textual particles instead of system tags.

## Guidelines
- **Laughter**: Write "哈哈" or "嘿嘿".
- **Sigh**: Write "唉" or "唔...".
- **Thinking/Pause**: Write "嗯..." or "让我想想...".
- **Clearing Throat**: Write "咳咳".
- **Emphasis**: Use particles like "啊", "呢", "吧", "哦".

## Prohibition
- NO `<|laughter|>`
- NO `<|sigh|>`
- NO `<|breathing|>`
- NO `<|coughing|>`
- NO `<|throat_clearing|>`
- NO `[笑]` (use "哈哈" instead)
