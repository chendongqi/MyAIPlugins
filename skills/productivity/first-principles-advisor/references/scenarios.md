# 场景手册

每个场景包含：**基本事实层**（该领域的第一性原理是什么）、**常见隐藏假设**（典型的 C/B 前提）、**关键问题**（按顺序问）、**推荐工具**、**案例编号**（见 cases.md）。

## 1. 商业战略 / 新业务 / 进入市场

**基本事实层**
- 用户被这个生意"雇佣"完成的底层任务（JTBD）
- 10 年内不会变的用户需求（贝索斯：客户想要低价、快、丰富选择）
- 从零构建的真实成本结构
- 真实的付费意愿（不是"大家觉得值多少"，而是"现在在用什么替代、付多少"）

**常见隐藏假设**
- "市场在增长，所以进入就安全"（C）
- "竞品在做，所以可行"（C）
- "我的点子不一样"（B，未验证）
- "先做出来再找用户"（C）

**关键问题**
1. 用户到底在"雇佣"这个生意完成什么任务？
2. 用户今天的替代方案是什么？成本多少？体验缺口在哪？
3. 如果头部 3 家竞品明天消失，用户会来吗？（检验需求真实性）
4. 这个行业 10 年不变的是什么？变的是什么？
5. 从零构建的真实成本结构 vs 行业售价，差在哪一环？

**推荐工具**：JTBD、十年不变、成本结构拆解、白板重构
**案例**：C4（亚马逊）、C5（Netflix）、C1（SpaceX 电池）

## 2. 产品设计 / 功能 / MVP

**基本事实层**
- JTBD：用户雇佣产品完成的任务（不是功能，是任务）
- 用户当前的替代行为（哪怕替代物是"Excel + 手工"）
- 真实使用场景与频率
- 完成该任务的**最小形态**

**常见隐藏假设**
- "用户想要这个功能"（B，未验证）
- "功能越多越好"（C）
- "用户不会用，所以要做得复杂/要教育市场"（B）
- "竞品有，我们也要有"（C）

**关键问题**
1. 用户雇佣它完成什么任务？（用用户的话说）
2. 用户现在怎么完成这个任务？哪个环节最痛？
3. 最终体验写成新闻稿，用户会兴奋吗？（逆向工作）
4. 完成这个任务的最小形态是什么？（砍到只剩任务本身）
5. 哪个 20% 的功能驱动 80% 的使用？

**推荐工具**：JTBD、逆向工作 PR/FAQ、80/20、最小实验
**案例**：C8（克里斯坦森的钻头）、C6（苹果 2×2）

## 3. 定价与成本

**基本事实层**
- 价格 = 原材料 + 工艺 + 渠道 + 品牌溢价（逐项拆到可验证）
- 客户付的是**价值锚点**，不是成本（价值锚 = 替代方案的成本/收益）
- 单位经济：每服务一个客户的边际成本与边际收益
- 不同客群的价格敏感度分布

**常见隐藏假设**
- "价格一直这么高，所以合理"（C）
- "成本加成定价"（C，把成本当定价依据）
- "用户都嫌贵"（B）
- "降价是唯一增长手段"（C）

**关键问题**
1. 把现在的价格逐项拆：材料/工艺/渠道/品牌各占多少？
2. 哪一环是不合理溢价？（行业惯例加价 vs 真实成本差）
3. 从零自建这个产品/服务，真实成本是多少？
4. 客户在为什么付钱？（价值锚是什么：省多少、赚多少、替代物多贵）
5. 哪 20% 的客群不敏感？能否分层定价？

**推荐工具**：成本结构拆解、逆向（怎么保证没人买）、80/20
**案例**：C1（SpaceX 电池 $600→$80/kWh）、C7（特斯拉定价）

## 4. 商业模式 / 变现

**基本事实层**
- 价值链上真正创造价值的环节（而不是最吵的环节）
- 谁付费、谁受益、谁承担成本（三者经常不一致）
- 单位经济：每多做一单，边际成本与边际收益
- 付费方"自己干"的替代成本（为什么付费而不是自建）

**常见隐藏假设**
- "规模大=模式好"（C）
- "大家都用广告/订阅/佣金"（C）
- "免费获客再变现"（C，未验证转化）
- "收入=价值"（B）

**关键问题**
1. 价值链上哪一环真正创造价值？现在被谁拿走了？
2. 单位经济：第 1 单和第 10000 单，赚钱能力变化如何？（有无复利/规模效应）
3. 付费方为什么付费而不是自建？这个理由可持续吗？
4. 收入结构里，哪部分是"卖一次"，哪部分是"持续产生"？
5. 如果明天出现免费替代品，哪部分收入先死？

**推荐工具**：成本结构拆解、定价权、80/20、十年不变
**案例**：C4（亚马逊）、C5（Netflix 从卖 DVD 到卖娱乐）

## 5. 竞争与护城河

**基本事实层**
- 定价权的真实来源：转换成本 / 网络效应 / 成本优势 / 品牌 / 牌照
- 真实成本差（不是"我们效率高"，而是低多少、来自哪）
- 竞争对手复制的最小步骤（他抄你要几步？）

**常见隐藏假设**
- "我们产品更好，所以能赢"（B）
- "有专利=有护城河"（C）
- "先发=安全"（C）
- "烧钱能把对手烧死"（B）

**关键问题**
1. 凭什么能比竞品收更多钱？（定价权来源，说得出才存在）
2. 如果 10 倍资源的对手明天完整复制我们，什么挡住他？
3. 这个优势随时间增强还是减弱？（护城河会自己变窄）
4. 对手抄我们要几步？每一步的真实成本？
5. 用户离开我们要付出什么？（转换成本具体化）

**推荐工具**：定价权（巴菲特）、逆向（怎么保证被杀死）、成本结构拆解
**案例**：C11（巴菲特定价权）、C4（亚马逊飞轮）

## 6. 投资与理财

**基本事实层**
- 资产的内在价值 = 未来现金流折现 / 自用价值（与"现在市价"无关）
- 最坏情况的概率与损失幅度（不是期望值，是"扛不扛得住"）
- 货币的时间价值（复利）
- 自己的信息边界（能力圈）

**常见隐藏假设**
- "大家都在买，所以好"（C）
- "跌了很多，所以便宜"（B，锚定+沉没成本）
- "这次不一样"（C）
- "我能比市场判断得准"（B，未验证）

**关键问题**
1. 如果是卖方，这个价格我愿意卖吗？（对称检验）
2. 最坏情况亏多少？亏光/亏 50% 我扛得住吗？（先答这个）
3. 排除"已经涨了/跌了"的故事，这个东西值多少？
4. 我凭什么知道别人不知道的？（能力圈检验；答不出=不投）
5. 出现什么证据我会改主意？（先写下来）

**推荐工具**：逆向、事前验尸、沉没成本检验、证伪条件、能力圈
**案例**：C10（芒格逆向）、C11（巴菲特定价权）

## 7. 职业与跳槽

**基本事实层**
- 自己的能力结构：哪些能力市场付费、付多少
- 自己不愿牺牲的东西（时间、地点、收入下限、健康）
- 市场的底层需求（行业在解决什么问题，10 年还在不在）
- 机会成本：留下的真实成本（不只是没涨的工资）

**常见隐藏假设**
- "这个行业在风口，所以值得去"（C）
- "头衔好听"（B）
- "干了 N 年，现在走就浪费了"（B，沉没成本）
- "稳定=安全"（C）

**关键问题**
1. 市场底层需要什么样的能力？10 年还在需要吗？
2. 我哪些能力是"别人难替代 + 市场付费 + 我愿意持续投入"的交集？
3. 我绝对不能牺牲什么？（写出来，作为硬约束）
4. 若之前没投入这 N 年，今天我会选这条路吗？（沉没成本检验）
5. 3 年后回看，怎样会后悔？（逆向；列出来看现状命中几条）

**推荐工具**：沉没成本检验、逆向、80/20（哪项能力杠杆最大）、十年不变
**案例**：C10（芒格逆向）

## 8. 组织与管理（招聘/架构/流程）

**基本事实层**
- 公司的本质目的（丰田经典问题：我们存在的本质目的是什么？）
- 每个流程/岗位/层级服务于哪个根本目标
- 协调成本：人越多，沟通路径按 n(n-1)/2 增长
- 信息流：决策质量 = 信息质量（"最好的流程获胜"）

**常见隐藏假设**
- "这个流程一直有，所以有用"（C）
- "团队越大越快"（B）
- "业务大了要加管理层级"（C）
- "流程是为了管理，不是为了结果"（C）

**关键问题**
1. 公司的本质目的是什么？（一句话；所有流程由此证成）
2. 这个流程/岗位服务于哪个根本目标？答不出 → 删
3. 今天重新组建团队，会留哪几个人？（招聘的逆向）
4. 这个决策的信息来自哪里？能不能让"最好的信息获胜"而不是"最大的官获胜"？
5. 加一个人/一层，协调成本增加多少？收益增加多少？

**推荐工具**：五问法、白板重构（流程/架构）、80/20、逆向工作（决策机制）
**案例**：C6（苹果 2×2）、C9（丰田五问）、C12（亚马逊"最好的流程获胜"）

## 9. 资源分配（时间/钱/注意力）

**基本事实层**
- 真正的稀缺约束（人只有 24 小时、只有 Y 元、只有 N 个高精力时段）
- 各选项的收益分布（多数是幂律：少数动作贡献绝大多数结果）
- 复利结构：哪些投入随时间增值，哪些是一次性消耗

**常见隐藏假设**
- "忙=有价值"（C）
- "平均分配最公平/最稳"（C）
- "多线并行效率高"（B，切换成本被忽略）
- "贵的=值的"（B）

**关键问题**
1. 最稀缺的约束是什么？（不是钱，可能是注意力/时间）
2. 哪 20% 的动作驱动 80% 的结果？（识别后先保这 20%）
3. 哪些投入有复利（技能、资产、信任），哪些是一次性消耗（会议、救火）？
4. 每个选项的**机会成本**：做它意味着不做什么？
5. 砍掉哪 20% 对结果影响最小？（先砍，再谈加）

**推荐工具**：80/20、机会成本、沉没成本检验
**案例**：C6（苹果聚焦）、C9（丰田聚焦根因）

## 10. 谈判与沟通

**基本事实层**
- 对方底层要什么：安全 / 被理解 / 利益 / 面子（表面要价 ≠ 底层需求）
- 自己的 BATNA（最佳替代方案：谈不成我去哪）
- 蛋糕结构：是切蛋糕，还是存在把蛋糕做大的选项

**常见隐藏假设**
- "谈判是零和输赢"（C）
- "我强硬，对方就会让步"（B）
- "降价=让步=我输了"（C）
- "对方要价高=他很有底气"（B）

**关键问题**
1. 对方**底层**要什么？（不是他开价，是他为什么开这个价）
2. 我的 BATNA 是什么？谈不成我去哪？（没有 BATNA 就没有谈判力）
3. 有没有"做大蛋糕"的选项（换标的、换时间、加维度）而不是只切现有蛋糕？
4. 怎样保证这次谈判破裂？（逆向；列出来看现状命中几条）
5. 如果对方什么都得不到，他会接受什么？（他的真实底线）

**推荐工具**：逆向、JTBD（用在对方身上）、能力圈（不猜对方心理，要信息）
**案例**：C10（逆向）

## 11. 学习与技能投入

**基本事实层**
- 技能半衰期：这个技能多久贬值一半（工具类快、原理类慢）
- 复利结构：与已有能力是否叠加（1+1>2 还是并列）
- 底层原理：这个技能背后的一层原理，能否一句话讲清
- 市场对该技能的需求与付费（需求侧验证，不是供给侧热度）

**常见隐藏假设**
- "热门=值得学"（C，热度≠需求≠你能变现）
- "课越多成长越多"（B，输入≠输出）
- "学完再用"（C）
- "别人都在学，我不学就落后"（C）

**关键问题**
1. 这个技能的半衰期多长？（1 年？10 年？）
2. 它和现有能力叠加吗？（复利还是并列）
3. 它的底层原理是什么？能一句话说清吗？（费曼检验；说不清=还没入门）
4. 市场真的在为这个技能付费吗？（找 3 个真实案例验证）
5. 最便宜的"学"是什么？（做一个小项目 > 上十个课）

**推荐工具**：费曼技巧、80/20、最小实验、十年不变（选原理级技能）
**案例**：C9（丰田：学原理不学套路）

## 12. 人生重大决策（搬迁/大额/健康/关系）

**基本事实层**
- 可逆性：这个决定反转要付出什么（可逆的快决策，不可逆的慢决策）
- 全生命周期成本：不是标签价，是持有/维护/退出成本
- 自己的底层需求：安全 / 自由 / 健康 / 关系（排序）
- 退出条件：什么情况下我会撤（先写，防事后合理化）

**常见隐藏假设**
- "想了很久，是时候了"（B，用思考时长冒充决策依据）
- "更大/更好的那个更值"（C）
- "健康=没症状"（C）
- "大家都这么选"（C）
- "现在不做就来不及了"（B，制造紧迫感）

**关键问题**
1. 这个决定可逆吗？反转成本多少？（不可逆 → 默认慢下来）
2. 全生命周期成本多少？（买 + 持有 + 退出）
3. 我底层要什么？（安全/自由/健康/关系，排序后对照选项）
4. 若没有之前所有的"应该"，我今天会做这个选择吗？（沉没成本检验）
5. 怎样保证这个决定 5 年后让我后悔？（逆向；命中 2 条以上就停）
6. 什么证据出现我会撤？（退出条件先写下来）

**推荐工具**：沉没成本检验、逆向、事前验尸、证伪条件
**案例**：C10（芒格逆向）
