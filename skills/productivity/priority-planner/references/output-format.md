# 输出格式规范

## 目录与命名

```
<输入目录>/goals/
├── annual-2026.md
├── quarterly-2026-Q4.md
├── monthly-2026-10.md
├── weekly-2026-W42.md      # ISO 周：date +%G-W%V
└── daily-2026-10-12.md
```

- 周文件标题带日期范围（周一~周日）：`第 42 周（10-12 ~ 10-18）`
- 只写有内容的层；高层缺失时，低层文件头注明 `> 上游: 年度目标待定义`

## 元信息头（每个文件必须有）

```
# <层级> <周期>
> 更新: YYYY-MM-DD | 来源: <文件列表/对话> | 峰值精力: <HH:MM-HH:MM 或 待填>
```

## 行格式

**任务行**：
```
- [ ] <next action：动词开头、物理可观察> | 服务: <目标ID 或 无> | 级别: A1 | 影响/努力: 高/低
  - 时间块: <可选，如 周二 09:00-11:00>
```
- 状态：`- [ ]` 待办 / `- [x]` 已完成（定期移入"已完成（归档）"）
- 目标 ID 稳定：A1(年) / WIG-1(季) / M1(月)；周/日的 One Thing 用当层 `A1` 指代
- @等待项不进任务行，进日文件"按上下文"区

**目标行**（年/季/月）：
```
### A1 <目标一句话>
- 为什么: <极致测试通过的理由>
- 滞后指标: <可量化>
- 派生: <下层文件名 + ID>
```

## 合并更新规则（层级文件已存在时）

1. 先完整读原文件，再写
2. 仍有效的项：保留原措辞与 ID（ID 稳定，跨层"服务:"引用依赖它）
3. 已完成项：移入"已完成（归档）"
4. 本轮被裁/过期项：移入"裁剪/推迟"，必须写理由
5. 新增项：按行格式追加到对应区
6. 更新元信息头：更新日、来源（追加新来源）、峰值精力（若用户提供了）
7. 跨层一致性检查：
   - 周/日任务必须能挂到某个 WIG/里程碑；挂不上的标 `服务: 无` 并提醒
   - 某 WIG 连续 2 周无任务支撑 → 在周文件标注 `⚠ WIG-x 无支撑任务`
   - 年度目标变了 → 检查下层派生是否失效，失效项进裁剪区

## 空层处理

- 高层为空（如只有周/日内容）：低层文件头写 `> 上游: 年度目标待定义（建议运行 bootstrap）`
- 某层本轮无新增也无变更：不写该文件，不重写
- bootstrap 全流程跑完：5 个文件都建，即使某层只有 1 项
