## 诊断式提问清单

### 项目基本信息
- 项目当前处于什么阶段？(想法期/MVP期/增长期/成熟期)
- 项目启动多久了？团队规模如何？
- 目前的资金状况和燃烧率是怎样的？

### 产品与市场
- 你的目标用户是谁？能描述3个典型用户画像吗？
- 用户的核心痛点是什么？你如何验证这个痛点的？
- 目前的产品解决方案是什么？与竞品相比的差异化在哪？
- 产品的核心竞争优势和护城河是什么？

### 商业模式
- 当前的盈利模式是什么？
- 单位经济模型如何？(CAC、LTV、边际成本等)
- 现金流状况如何？多久能实现盈亏平衡？

### 团队与资源
- 团队成员的背景和分工是什么？
- 目前最缺什么资源？(技术、资金、渠道、人才)
- 团队内部协作有什么挑战？

### 核心挑战
- 目前面临的最大3个挑战是什么？
- 这些挑战是如何影响业务发展的？
- 你尝试过什么解决方案？效果如何？

## 结构化建议模板

### 1. 现状分析
```
**项目阶段**: [想法期/MVP期/增长期/成熟期]
**核心优势**:
- [优势1]
- [优势2]

**主要问题**:
- [问题1 + 影响分析]
- [问题2 + 影响分析]

**机会窗口**: [市场时机分析]
```

### 2. 优先级排序
```
**立即处理（P0）**:
- [问题] - 原因：[阻碍核心业务/财务风险/法律风险]

**近期处理（P1）**:
- [问题] - 原因：[影响增长/用户体验]

**可延后（P2）**:
- [问题] - 原因：[优化项/非关键路径]
```

### 3. 行动方案
每个方案包含：
```
**方案 [N]: [方案名称]**

**目标**: [具体、可衡量的目标]

**执行步骤**:
1. [步骤1] - 预计时间: [X天/周]
   - 具体做法: [详细说明]
   - 所需资源: [人力/资金/工具]
   - 负责人: [建议角色]

2. [步骤2] - 预计时间: [X天/周]
   ...

**成功标准**: [如何判断成功]

**潜在障碍**:
- [障碍1] → 应对方案: [...]
- [障碍2] → 应对方案: [...]

**预期成果**: [量化结果]
```

### 4. 关键指标
```
**北极星指标**: [最核心的指标]

**过程指标**:
- [指标1]: 当前值 [X], 目标值 [Y], 时间节点 [Z]
- [指标2]: ...

**监控频率**: [每日/每周/每月]
```

### 5. 风险提示
```
**高风险项**:
- [风险描述] - 概率: [高/中/低], 影响: [严重/中等/轻微]
  缓解措施: [...]

**常见陷阱**:
- [陷阱1]
- [陷阱2]
```

### 6. 资源推荐
```
**学习资源**:
- 书籍: [书名] - 适用场景: [...]
- 文章: [链接] - 核心观点: [...]

**工具推荐**:
- [工具名] - 用途: [...] - 费用: [...]

**社群与导师**:
- [社群/活动名称] - 价值: [...]
```

## 关键指标体系

### 早期项目 (想法期/MVP期)
- **核心指标**:
  - 问题验证: 有多少目标用户确认这个痛点？
  - 解决方案验证: 用户愿意为此付费吗？付多少？
  - 早期留存: D1/D7/D30 留存率

### 增长期项目
- **增长指标**:
  - 用户获取: CAC (获客成本), 获客渠道 ROI
  - 激活: 注册-首次使用转化率
  - 留存: 月留存率, 流失原因分析
  - 收入: MRR, ARPU, LTV
  - 推荐: NPS, 病毒系数 K

- **单位经济模型**:
  - LTV/CAC > 3 (健康阈值)
  - CAC 回收期 < 12个月

### 成熟期项目
- **规模化指标**:
  - 营收增长率
  - 利润率
  - 市场份额
  - 客户满意度
  - 团队效能

## 常见场景应对指南

### 场景1: 找不到盈利模式
**诊断重点**:
- 用户是否真的愿意为价值付费？
- 是否存在更愿意付费的细分用户群？
- 是否存在间接变现途径？(广告、数据、增值服务)

**常见方案**:
1. 免费增值模式: 核心功能免费，高级功能付费
2. SaaS订阅: 按月/年收费
3. 交易抽成: 平台模式
4. 企业服务: B2C验证后转B2B

**案例参考**: [一人企业方法论 - 产品池与支付能力]

### 场景2: 用户留存率低
**诊断重点**:
- 用户流失发生在哪个环节？(激活/首次使用/持续使用)
- 流失用户与留存用户的行为差异是什么？
- 产品是否真正解决了用户的高频痛点？

**常见方案**:
1. Aha Moment 优化: 缩短用户获得首次价值的时间
2. 引导优化: 新手教程、使用提示
3. 习惯养成: 推送、激励机制
4. 产品迭代: 基于流失用户反馈改进核心功能

**关键指标**: D1/D7/D30 留存率, Aha Moment 到达率

### 场景3: 融资准备
**准备清单**:
- [ ] BP (商业计划书): 10-15页, 讲清楚问题-方案-市场-团队-数据
- [ ] 财务模型: 3年预测, 关键假设说明
- [ ] 产品Demo: 可演示的MVP或视频
- [ ] 数据资料: 用户数据、财务数据、市场数据
- [ ] 公司资料: 股权结构、法律文件

**BP 核心结构**:
1. 问题与机会 (1页)
2. 解决方案 (2页)
3. 市场规模 (1页)
4. 商业模式 (1页)
5. 竞争分析 (1页)
6. 核心数据 (2页)
7. 团队介绍 (1页)
8. 融资计划 (1页)

**投资人关注点**:
- 市场: TAM是否足够大？增长趋势如何？
- 团队: 是否有行业经验？执行力如何？
- 产品: 是否有清晰的竞争优势？
- 数据: 增长曲线是否健康？单位经济模型是否成立？

### 场景4: 团队内部冲突
**诊断重点**:
- 冲突的根本原因是什么？(愿景分歧/利益分歧/沟通问题)
- 双方的诉求和顾虑是什么？
- 是否涉及核心价值观差异？

**应对框架**:
1. **理解阶段**: 分别倾听双方观点，避免站队
2. **澄清阶段**: 帮助双方理解对方的真实诉求
3. **方案阶段**: 引导寻找双赢方案
4. **机制阶段**: 建立决策机制，避免类似冲突

**预防机制**:
- 定期1on1沟通
- 明确决策权限
- 股权激励与退出机制
- OKR对齐

### 场景5: 资源有限，不知道优先做什么
**判断框架 (ICE评分法)**:
```
每个任务打分 (1-10分):
- Impact (影响): 对核心目标的影响程度
- Confidence (信心): 成功概率
- Ease (容易度): 执行难度的倒数

ICE Score = (Impact × Confidence × Ease) / 3
```

**优先级原则**:
1. 优先做能快速验证核心假设的事
2. 优先做杠杆率高的事 (投入产出比高)
3. 优先做能形成飞轮效应的事
4. 对于一人企业，优先做可扩展的事

参考: [一人企业方法论 - 为什么可扩展性是可能的]

## 使用指南

1. **咨询流程**:
   - 使用诊断式提问清单了解情况
   - 基于结构化建议模板组织建议
   - 提供行动计划模板帮助落地
   - 定义关键指标追踪进展

2. **灵活调整**:
   - 根据项目阶段选择合适的框架
   - 根据创业者经验调整建议深度
   - 考虑行业特性和资源约束

3. **持续跟进**:
   - 在关键节点询问进展
   - 根据反馈调整方案
   - 建立复盘习惯
