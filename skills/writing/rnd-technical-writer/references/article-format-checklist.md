# 文章格式检查清单

本检查清单用于验证技术博客文章是否符合格式规范。在完成文章写作后，必须逐项检查。

---

## Frontmatter 检查

- [ ] 文件以 `---` 开头的 YAML frontmatter 开始
- [ ] `title` 字段存在且不为空
- [ ] `date` 字段格式为 YYYY-MM-DD（如 2025-01-05）
- [ ] `description` 字段存在，长度 50-100 字
- [ ] `tags` 字段为数组格式，包含 3-5 个标签
- [ ] `category` 字段存在且不为空
- [ ] `draft` 字段存在（true/false）
- [ ] frontmatter 以 `---` 正确闭合

## 标题结构检查

- [ ] 正文从二级标题 `##` 开始（一级标题由 title 生成）
- [ ] 标题层级无跳跃（不能从 `##` 直接到 `####`）
- [ ] 每个标题前有空行（文件开头除外）
- [ ] 每个标题后有空行
- [ ] 标题文字简洁明了

## 文本格式检查

- [ ] 粗体使用 `**文本**` 格式
- [ ] 斜体使用 `*文本*` 格式
- [ ] 行内代码使用反引号 `` `代码` ``
- [ ] 段落之间有空行分隔
- [ ] 无连续多个空行

## 代码块检查

- [ ] 所有代码块使用三反引号包裹
- [ ] 代码块指定了语言类型（如 ```kotlin, ```python）
- [ ] 代码块内容缩进正确
- [ ] 代码示例可运行或已标注为伪代码
- [ ] 重要代码有注释说明

## 图片检查

- [ ] 所有图片都有 alt 描述文字
- [ ] 本地图片路径格式：`![描述](./images/name.png)`
- [ ] 网络图片使用完整 URL
- [ ] 图片文件存在（本地图片）
- [ ] 图片说明使用斜体：`*图片说明*`

## 链接检查

- [ ] 链接格式正确：`[文字](URL)`
- [ ] 外部链接使用完整 URL（https://...）
- [ ] 站内链接使用相对路径（/blog/...）
- [ ] 链接文字有意义（避免"点击这里"）

## 表格检查

- [ ] 表格使用 `|` 分隔列
- [ ] 表头与内容之间有分隔行 `|---|---|`
- [ ] 对齐符号使用正确（`:---` 左, `:---:` 中, `---:` 右）
- [ ] 表格前后各有空行
- [ ] 表格内容对齐整齐

## 引用与提示框检查

- [ ] 引用使用 `>` 符号
- [ ] 提示框使用正确的 Callout 语法
- [ ] Callout type 为有效值（info/tip/warning/error）
- [ ] 提示框内容简洁有用

## 文件格式检查

- [ ] 文件编码为 UTF-8
- [ ] 文件扩展名为 `.md` 或 `.mdx`
- [ ] 文件以空行结尾
- [ ] 无多余的尾部空格

## 内容完整性检查

- [ ] 文章有引言/概述部分
- [ ] 核心内容完整
- [ ] 有总结/结论部分
- [ ] 相关文章链接（如有）格式正确
